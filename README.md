## The entry

🌴

One palm tree (U+1F334, a single code point) — a tropical island
dream vacation in a single character. The program writes exactly
this emoji, and nothing else, to `/output/entry.txt`.

A palm tree on a warm shore — the whole trip in a single character.
No words, no itinerary, just the place you picture when someone says
"dream vacation".

## Run

```sh
python3 main.py
```

This writes exactly one emoji to `/output/entry.txt`.
